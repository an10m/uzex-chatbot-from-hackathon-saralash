# Текст для поля «Технологии и методы» (RU)

Прототип — Telegram-бот на Python, который отвечает на вопросы по реестру из
500 000 сделок на узбекском и русском языках. Данные из CSV загружаются в
SQLite; при загрузке рассчитываются физический объём (количество лотов × лот),
суммы в сумах и долларах по курсу на дату сделки, флаги статусов, год/месяц/
квартал и индексы. Gemini Flash (3.5 Flash Lite с автоматическим переходом на
другую доступную Flash-модель) используется только как планировщик запроса: он
возвращает JSON с намерением и SQL, а все числа, названия компаний и коды
берутся из результата SQL и подставляются детерминированными двуязычными
шаблонами. Поэтому модель не может придумать цифру или компанию.

Перед выполнением SQL проходит защиту: разрешены только SELECT/WITH, только
шесть таблиц, read-only соединение, authorizer, таймаут 8 секунд и лимит строк.
Названия товаров, регионов, статусов, компаний, брокеров и единиц
разрешаются по реальным значениям базы с учётом узбекских, русских и
английских алиасов; неоднозначные названия приводят к уточняющему вопросу.
Если ответа в данных нет (прогноз, политика, погода, прибыль, телефон,
несуществующая компания), бот прямо сообщает об этом. Под каждым ответом
показывается блок «Источник» с SQL-запросом, числом строк, периодом и охватом
статусов — проверяющий может воспроизвести результат.

По умолчанию учитываются все строки реестра, включая аннулированные (об этом
сказано в источнике); по явному запросу «исполненные» фильтруется
is_completed=1, по запросу «аннулированные» — is_canceled=1. Язык ответа
определяется по вопросу; поддерживаются узбекская латиница, узбекская
кириллица и русский. Бот развёрнут на постоянно работающей VM под systemd,
доступен по ссылке без установки и регистрации; 55 офлайн-тестов, живой
прогон и отдельная проверка безопасности (allowlist SQL-функций, HTML-
инъекции, лимит запросов) сверяют ответы с независимыми SQL-запросами.
